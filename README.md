# netwatch

A lightweight, cross-platform CLI tool for network diagnostics written in **Go**.

## About

`netwatch` provides a simple overview of network connectivity and basic network health directly from the command line.

It is designed to monitor:

* Host availability and latency
* TCP port connectivity
* DNS resolution
* Packet loss
* Traceroute information
* Continuous network status

The tool supports both human-readable terminal output and machine-readable JSON output.
